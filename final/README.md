# The Beginner Developer Glossary — WDD231 Final Project

Three-page individual website project: Home, Glossary, and Learning Path.

Required functionality implemented: local JSON Fetch API; async/await; try/catch; 20 dynamic terms with six properties each; search/filter; array methods; template literals; ES modules; accessible native dialog; localStorage favorites and theme preference; responsive navigation; responsive layout; HTML GET form with action page; dynamic year/last-modified; favicon; SEO descriptions; author metadata; Open Graph metadata; attribution page; project-demonstration page.

The project demonstration video is on YouTube (https://youtu.be/qOJpiYRVOtM) and is linked from the footer of every page; `video.html` also shows a clickable preview of it.
