# The Beginner Developer Glossary — WDD231 Final Project

Three-page individual website project: Home, Glossary, and Learning Path.

Required functionality implemented: local JSON Fetch API; async/await; try/catch; 20 dynamic terms with six properties each; search/filter; array methods; template literals; ES modules; accessible native dialog; localStorage favorites and theme preference; responsive navigation; responsive layout; HTML GET form with action page; dynamic year/last-modified; favicon; SEO descriptions; author metadata; Open Graph metadata; attribution page; project-demonstration information page.

The demonstration page honestly explains that a qualifying face-and-screen recording could not be produced because the available laptop has a poor camera and a non-working microphone. No fictional video URL is provided.
