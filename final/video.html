Project demonstration

A video demonstration is normally provided here to show the project's JavaScript data integration and asynchronous functionality.

Video unavailable

At the time of submission, I do not have the equipment required to produce the requested face-and-screen demonstration video. My available laptop has a poor camera and its microphone does not work, which prevents me from creating a recording that meets the stated video requirements.

The project itself contains the required functionality and the JavaScript implementation can be inspected directly in the project files and demonstrated through the working website.

What the demonstration would cover

  • Fetching the glossary JSON data with the Fetch API.
  • Using async/await and try/catch for asynchronous data loading.
  • Dynamically generating glossary cards from the data.
  • Searching, filtering, and using array methods.
  • Using localStorage for saved glossary terms and theme preference.
  • Opening and interacting with the accessible term-detail dialog.
